- Listen with friends: start a room in the cast button's menu, or in
  Settings › Desktop, and friends on the same network join it with its
  6-character code or its invite link, see who hosts, what plays and
  how many listen, and hear what you play, in step, on their own
  computers, within about 50 ms. The code is never sent, and 5 wrong
  ones make a computer wait a minute. The host removes or blocks a
  guest; a guest that drops off comes back by itself, and gets its own
  queue back as it leaves. Your audio is never sent: each computer plays
  the same track from where it can (#561).
